# Eventify

Eventify is a web-based event planning platform that helps users explore event themes and products based on their event type and budget. The project was developed collaboratively, with separate responsibilities for frontend development and backend integration.

## 🚀 Live Demo

[Visit Eventify](https://eventify-ruddy-rho.vercel.app/)

## ✨ Features

- 🎉 Browse event themes based on event type
- 💰 Explore themes according to budget range
- 🛍️ View products associated with each theme
- 🔐 User authentication
- 🗄️ Supabase database integration
- 👤 User account management
- 📱 Responsive and interactive user interface

## 🛠️ Technologies Used

- React.js
- TypeScript
- Supabase
- JavaScript
- HTML
- CSS
- Vercel

## 🏗️ System Overview

Eventify consists of a frontend interface for browsing and interacting with event themes and a backend powered by Supabase for data management and authentication.

The application uses Supabase to store and manage application data and handle user authentication.
